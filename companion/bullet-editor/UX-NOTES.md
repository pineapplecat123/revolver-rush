# 子弹编辑器 UX / 长图导出

仅编辑器表述改动（四颗公式弹的基础伤害显示 X 并补公式备注），不修改游戏机制、运行时子弹数值、提交协议或凭据。`game_description` 原样保留并显示为斜体（列表和长图导出均如此）；设计效果说明 `effect` 与备注保持正体。字段标签显示为「基础伤害」，支持数字、留空或公式占位 `X`。枪口强化提示使用【枪口火焰】【消耗枪口火焰】【火焰层数】，不重写记录内容、不处理敌人计时器。

- 新版首次打开会把旧的排序偏好迁移为「更新时间 / 降序」；之后仍可选择并记住其他排序。缺少更新时间时回退创建时间。
- 类型/流派/稀有度下拉显示数量。每个维度的数量遵循搜索、入库标签和其他维度，但不受自身维度限制；零结果选项仍可选择。下方同时列出各流派/类型数量，包含未填写项。只统计已确认数据，不把待确认提交重复计算。
- 表单提供真正的流派下拉，同时保留自由文本输入。已有数据、待确认提交、当前新输入的流派自动成为选项；不会把新增限制在已有选项中。
- 打开导出面板时，按当前排序复制已确认数据快照，默认勾选当前筛选结果。可切换全选/清空、逐条勾选子弹、选择字段（名称始终保留）。轮询更新不打断快照或手动选择；重新打开面板获取新快照。
- 导出完全本地 Canvas → PNG Blob → 下载，不新增网络访问、第三方库、付费服务或数据写入。保留生成图片链接，兼容浏览器阻止自动下载的情况。
- 图片宽 1000px，先按实际字体测量并逐字换行，再计算所有卡片高度。显式换行/空行保留；不截断行或分页。超过 16000px 时明确拒绝并要求减少记录/字段，避免手机 Canvas 内存限制下得到空白/截断图；失败可重试。当前 28 条全字段用保守测量约 14698px。
- 字体：新增原生 `Noto Sans CJK SC` 回退项；Canvas 使用系统中文字体栈并等待 document.fonts.ready。无字体下载、无新字体资产、不使用游戏的裁剪版字体，不需重新生成游戏字库。仍需在目标系统确认中文/斜体与图片保存效果。
- 仅变更静态资源缓存查询标识，不改游戏版本。现有 publish_companion 的目录复制会自动带上 overview.js。

## 集成人员的人工浏览器检查（尚未执行）

在部署预览或本地静态服务（例如从本工作树执行 `python3 -m http.server 8765 --directory companion/bullet-editor`）中打开编辑器，使用正常解锁流程；不要提交测试记录。

1. 先备份现有本地草稿。在手机窄屏和桌面确认默认「更新时间/降序」、排序选择持久化，游戏内描述为斜体，而效果说明和备注为正体；伤害标签为「基础伤害」。
2. 选择入库标签、搜索、流派和类型交叉筛选，核对各项计数与说明；零结果选项应保留。
3. 在未提交的表单输入新流派，确认下拉立即包含它；选已有流派应回填，仍可输入另一新流派。结束时恢复草稿，不提交。
4. 导出面板初始只勾选筛选结果；验证全选/清空/逐条勾选/字段勾选；等待一次轮询，手动选择不得重置。
5. 下载「全部 28 条/全字段」及「单条/仅名称、效果说明、游戏内描述」PNG；实际打开图片，检查汉字、状态色十六进制文字、长说明、空行、首尾记录完整、卡片不重叠、游戏内描述斜体、效果说明正体，基础伤害含 `X`。只有名称时也应成功。
6. 手机实际保存 PNG；自动下载被阻止时使用生成链接。空选择应明确报错且按钮恢复。超大内容拒绝而非裁切（自动测试覆盖，勿为此提交数据）。

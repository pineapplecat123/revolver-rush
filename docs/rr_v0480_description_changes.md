## 加伤弹 · `companion/bullet-editor/data.json` · `effect`

旧：射击后，给枪口挂上「加」状态：本弹夹剩余子弹伤害+50％，多个本子弹加法叠加。

新：开火后产生【枪口火焰】，每层伤害×1.5，多层逐层相乘。【火焰层数】本轮剩余实弹数。【消耗枪口火焰】自身公式伤害（含基础0的特殊公式）>0时，按生成顺序应用全部层，各效果减最早一层；零伤害或空仓不消耗、无弹道，开始不豁免。

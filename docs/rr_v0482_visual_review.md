# v0.4.82 枪口火焰朝向复查（已目视）

修正对象：v0.4.81 把持续火焰做成了向前的横向喷火/喷灯（被否定）。本次把枪口持续火焰改成向上燃烧、类似 🔥 的轮廓。强化弹道火焰仍向前飞，整枪不旋转。

## 证据（原生 720×1280，Movie Maker 30fps）

- `docs/shots/rr_v0482_wait_five.png` / `_muzzle.png`：5 层等待，火焰仍在。
- `docs/shots/rr_v0482_zero_five.png` / `_muzzle.png`：零伤害不消耗，5 层仍在。
- `docs/shots/rr_v0482_after_one.png` / `_muzzle.png`：一次有效开火后缩小为 3 层。
- `docs/shots/rr_v0482_upright_flame.mp4`：约 8 秒全屏短片；`rr_v0482_upright_flame_closeup.mp4` 为左上裁切。
- `docs/shots/rr_v0482_muzzle_orientation_before_after.png`：v0.4.81 横向喷火 vs v0.4.82 向上火焰。

日志：`envelope=(113, 178)`（5 层，高大于宽）；消耗后 `envelope=(87, 142)`，图标 5→3。

## 目视形状

火焰贴在枪口右侧、向上烧，不是水平喷柱。底部宽而圆，向上收束，顶部有不规则分叉火尖（左/中/右尖会轻微左右摇）。外层金黄、内层绿色（与当前状态色一致），能清楚看出分层。体积很大，5 层时高度明显超过角色。消耗后整体变矮变窄，层数为 0 时应熄灭（本短片未拍到熄灭帧，由既有消耗测试覆盖）。

## 仍在的问题

5 层时最高的火尖会盖住顶部「阶段：选择行动 / HP」字样，并接近「返回主菜单」「沙盒」按钮。这是按「必须很大、很明显」留下的取舍，不是朝向错误。没有改整枪朝向，也没有改弹道飞行方向。

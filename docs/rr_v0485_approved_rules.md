范围：t658、t661–t666。只在 `feat/gameplay-redo` 发布，未动 main、PIN、seal、认证或商店布局。表格 28 行全部入库；新增 ID 60–67 按表格顺序，保留原基础伤害与空稀有度。升级引爆原伤害字段为空，仍为空（effect 模式），没有填造普通射击伤害。

## 本批落地

- 总伤传递：本轮第一发至本发结算后的实际总伤害 S，N=开火开始的实弹数，N 层、每层 S/N；不是上一轮伤害，也不限制只在下一轮使用。遵循原有跨轮保留和按类型消耗。
- 双倍给下一个：本发不应用/消耗火焰；所有已有组的剩余层数各自翻倍，保留数值和顺序。
- 加强尾部：仅剩余未发射结束弹分摊本发实际伤害；每发同额，非结束弹不使用这组；轮末清剩余份额。
- 恐怖汲取：原基础1，每实际消耗一层×2；只数消耗而非应用，自身消耗不递归加强本发。引爆耗尽也计入后续汲取。
- 升级引爆：耗尽所有层，每个敌人每层4点，无额外普通射击、不叠火焰、不重复回声/导电链。
- 分裂尾弹：上一发对所有敌人的实际总额，火焰只算一次；对开火时的目标快照均分、每个目标向上取整，整发消耗一次。
- 吃拍：完整开火快照、环形首尾邻接；每邻空槽+100%自身伤害，已射出槽不新增空仓。
- 黑视：装填于开火快照即整轮生效；只虚拟空槽计数，不改实弹、位置公式或火焰结算。
- 尾加倍在轮到最后实弹时才生成，轮末仅清本类型（及本轮限定的加强尾部），其他类型照常跨轮。最后实弹即使自身零伤害也不回退，最后物理空槽不算子弹。
- 倍伤改文案；伤害递增、叠势最后取整本来已如此，未改伤害算法；模仿、重复开始补快照、嵌套、无来源、基础/公式与挂火焰边界，未发明新复制机制。

需要鼓励仅按要求替换成「每收到一层火焰加强」；**仍是基础3→6一次**，不是按层指数翻倍。文案与这一旧逻辑的潜在歧义已单列于游戏规则文末，未擅自拍板。

**暂缓三发**：总伤二分弹、传递弹、爆穿在编辑器和 ammo 的完整行对象均与 `ad9aa27` 相等；独有规则、数据与预计伤害口径没动。

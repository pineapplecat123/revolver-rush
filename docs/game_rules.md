# 游戏规则

本文件写的是已经确定、对所有相关子弹通用的规则。子弹表格和游戏内描述只写该子弹自己的生成条件、层数和倍率，不必再复制这里的普适段落。

实现默认与待定文案见文末，不要把实现里的权宜选择当成新的策划规则。

## 枪口火焰（已确定）

### 术语

- 【枪口火焰】：挂在枪口上、按层叠加的加强效果。
- 【火焰层数】：层数，不是秒数，也没有实时倒计时。
- 【消耗枪口火焰】：满足条件的射击在结算加强之后减少层数。

### 应用顺序

一发子弹先按自身公式算出「自身计算伤害」（包括基础伤害字段为 0、但另有公式的情况）。若自身计算伤害大于 0，再按火焰的**生成顺序**应用**当前全部层**，然后进入消耗；自身公式与火焰结算使用浮点值，最后才四舍五入（分裂尾弹明确规定的逐目标向上取整除外）。加减、乘倍的先后顺序会影响结果，因此生成顺序必须保留。

+50% 的一层按 ×1.5 计算，多层逐层相乘，不是把百分数先加在一起。

### 谁能吃到火焰、谁会消耗

- 资格只看这发子弹自己的计算伤害是否大于 0。平面加伤火焰不能把「自身公式本为 0」的功能弹抬成有伤害，从而再去消耗火焰。
- 自身计算伤害为 0 的普通射击，以及空仓：不获得火焰加持，不消耗层数，也不产生普通弹道。明示的功能弹特殊操作（如升级引爆消耗全部层）不属于普通射击。
- 开始类型**没有豁免**。只要自身计算伤害大于 0，开始弹同样应用并消耗火焰。
- 墙钟等待不会让火焰过期。敌人身上那些无关的状态计时器不在本规则里，也不被改成层数。

### 消耗方式

在本发已经应用完全部现存层之后，**每种效果各减少 1 层**。不是全局只减最早的一层，也不是把同一效果的全部组同时各减 1 层。

若同一种效果被分成多组、按不同时间挂上，则该类型只让**最早生成的那一组**减少 1 层；这是实现时采用的默认处理，见下方「实现默认」，不是另外一条新的策划规则。

部分子弹会写明自己的特殊作用对象（例如只作用于本轮最后一颗实弹）。那种限制写在该子弹自己的效果说明里，不在本普适段落重复。

### 显示（视觉）

- 「枪口：」右侧为每一层一枚独立的小火焰图标，颜色等于该效果在表格中的状态色。不要收成只显示 ×N，也不要用计时条代替层数。
- 枪口上的持续火焰是**向上燃烧**的火焰轮廓，类似于 🔥：底部宽而圆，向上收束，顶部有不规则的火尖；多层时按生成顺序分成内外层，使用各自的状态色。火焰明显、能看清，贴在枪口，不挡住顶栏。层数减少时整体变小，层数为 0 时熄灭。
- 它不是沿弹道向前喷出的喷灯，也不旋转整把枪。
- 新产生火焰时，枪口会有一次夸张的向上喷发，随后转为持续燃烧。
- 受到火焰加强的弹道可以带有向前飞行的火焰外形；弹道本身的飞行方向不变。

## 已验证的例子

下列数字已按当前规则核对。

### 混合加减与翻倍

生成顺序为三层 +50%（即每层 ×1.5），然后两层 ×2。基础伤害 3。

每发先吃当时还在的全部层，再让每种效果各减 1 层：

1. 3 × 1.5 × 1.5 × 1.5 × 2 × 2 = 40.5
2. 3 × 1.5 × 1.5 × 2 = 13.5
3. 3 × 1.5 = 4.5
4. 3
5. 3

单发最终伤害仍按现有规则四舍五入（远离零）：41、14、5、3、3。

### 传递弹的超额递减

传递弹在本发被加强时，按「四舍五入后的预计伤害 − 基础 3」（最低 0）产生同样层数、每层固定 +1 的火焰。空仓不推进这个递减。

- 超额 9，后面还有 3 发实弹：+9、+8、+7。不是守恒分配成 +4、+3、+2。
- 超额 2，后面还有 4 发实弹：+2、+1、+0、+0。

## 实现默认（不是新的策划规则）

这些是把已确定规则接到现有数据时采用的选择，列在这里以免被误写成新规则：

- 同一效果类型存在多组独立授予时，有伤害的一发只让该类型中最早的一组减 1 层，其余同类型组保持层数。
- 旧字段里按「本弹夹剩余实弹」计的持续时间，在生成时折成对应的【火焰层数】；旧的「打出一次就消耗」或「留给最后一发」生成 1 层。这不是墙钟倒计时。
- 未写明轮盘结束清除的火焰，在重新装填的计划重置后仍然保留，直到被消耗或本场战斗重置。尾加倍与仅作用于本轮剩余结束弹的加强尾部在本轮结束清除，不清除其他类型。
- 旧罪孽/元素枪口计时代码如果还留在工程里，没有被改写成新的层数；也没有给它们编造层数。

## 本批已确定的特殊规则（t658、t661–t666）

- 总伤传递弹：本发实际命中结算后，将本轮第一发至本发（含本发）的实际总伤害记为 S；N 为本轮开火开始时已装实弹数。生成 N 层、每层固定加伤 S/N 的火焰。仍然全部层先应用、每种效果消耗一层；可留到下一轮。例如 S=30、N=3，后续加伤 +30、+20、+10。不是只给下一轮平均分一次，也不是取上一轮的伤害。
- 双倍给下一个：本发完全不接受、不消耗火焰，发射时将当前所有已有火焰组的剩余层数分别翻倍；类型、每层数值与生成顺序不变。尚未生成的尾加倍火焰不算已有火焰。
- 加强尾部：按本发实际伤害与本轮尚未发射的结束弹数量等分。火焰只作用于结束弹，每发获得相同份额，不因剩余层数减少而变成不等份；中间弹不使用、不消耗它。没有剩余结束弹则不挂。未用份额在本轮结束清除。
- 恐怖汲取：使用表格原始基础伤害1。在本弹装填于本轮期间，每实际消耗一层火焰，自身伤害翻倍一次。只应用而未消耗不计；例如应用5层、实际消耗2层，×4。自身射击的消耗不递归加强已发出的本发；升级引爆消耗的所有层同样计入尚未发射的汲取。
- 升级引爆：原始伤害字段保持空；不是额外附带一次普通射击。消耗所有现有层，对开火时每个敌人造成每层4点伤害；引爆不接受火焰加强，也不再按普通方式消耗。没有火焰则伤害0。
- 分裂尾弹：复制上一发跨所有敌人的实际总伤害，只对总额应用一次本发火焰，再对本发开火时的存活目标快照均分，每目标向上取整；不先将总额四舍五入。整发仅进行一次正常消耗，无目标时不除以0。没有上一发实际伤害则为0。
- 吃拍：开火开始时完整物理弹仓的快照决定空槽，首尾环形相邻；已射出的槽不新增为空槽。每个相邻空槽使自身伤害+100%，然后叠火焰。
- 黑视：只要开火开始时已经装填，就从本轮开始生效，到本轮结束失效。仅空槽计数相关效果（空拍、吃拍）把所有槽视为空；不删除实弹、不改变位置公式、射击顺序或火焰应用/消耗。
- 尾加倍：由本弹授予的火焰等到最后一颗实弹轮到时才生成；最后是零伤功能弹也不回退寻找前面的有伤弹。最后按实弹而非最后物理空槽判定。本轮结束清除尾加倍自身的各组，其他类型照常保留。
- 倍伤弹：产生一层×1.5火焰，仅被自身计算有伤害的实弹消耗，文案不再将它称作无条件「下一颗」加强。
- 伤害递增、叠势：先算自身浮点公式，再叠火焰，最后取整。
- 模仿、重复开始：使用本轮开火开始的装填快照，复制来源技能而非来源实际伤害或枪口现存层。模仿只看前一槽、不跳空、不绕圈；重复开始向前找开始弹；连续复制递归解析，无来源则无技能，不以自身补位。模仿通常保留基础3；若技能本身为伤害公式，则按本发上下文计算。复制到会挂火焰的技能也会挂火焰。随机复制的候选仍只取其他尚未发射的实弹，不以自身补足。

### 实现接入说明（非新增策划数值）

- 加强尾部保存「每发固定份额」与剩余次数，不使用普通平面火焰的层数总和方式。多个授予组保留生成顺序；同类型仍按最早组消耗一层，轮末清理未用份额。
- 实际伤害规则沿用现有命中结算口径。含总伤传递、加强尾部或分裂尾弹的连射在前发视觉命中完成后再发下一发，防止将预测当作实际伤害。末发尚在飞行时，延后清理快照至末发结算。
- 原始表格的空稀有度原样保留；升级引爆空伤害以功能效果模式入库，没有补造数字。

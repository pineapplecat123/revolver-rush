# v0.4.94 验证

- 根因：出球看起来像飘，不是重力常数太小（仍与弹药袋同为 2100）。两处把出球口到托盘的速度压住了：
  1. `METER_EXIT_SPEED` 一直限到 `outlet_reveal_y + 半径`，几乎贴到出球口，球以 120px/s 从口里慢慢爬出。
  2. 球一过闸，闸门开始关闭；`_gate_open < 0.15` 后 `_physics_world` 对所有球每子步乘 0.96（每帧约 0.83）。这本应用来让罩内球沉降，却也打在正在下落的出球上，终端速度只有约 370px/s，看起来像飘到托盘。
- 修正：计量闸限速只在整球过闸前生效，过闸后按重力自由下落。0.96 沉降阻尼只作用于罩内非出球。`GRAVITY` / `AIR_DRAG` 与弹药袋共用值未改，倒出和手区物理堆不受影响。托盘弹性仍为 0.62。
- 测试：v0.4.81 出球口慢速露出的断言已按重力下落改写（不再要求 8 帧、每帧 ≤ 半径/3）。出球口到托盘接触 ≤ 0.55 秒（实测约 0.33 秒），帧位移 > 12px（实测约 32px），仍有弹跳、不瞬移。
- 视觉：`docs/shots/rr_v0494_candy_drop.mp4`（720×1280）。球从出球口重力落下，碰到托盘弹跳。

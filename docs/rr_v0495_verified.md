# v0.4.95 验证

- 需求：出球从出球口落到托盘时不要直上直下，给一次向左或向右、大小随机的力，让球偏着落下并在托盘上滚一下。保持 v0.4.94 的重力下落和弹跳。
- 做法：payload 第一次到达出球口（`outlet_point().y`）时加一次水平冲量，范围 [180, 300] px/s，符号随机左右。只加一次，计量闸限速期间不加。出球口以下不再用细滑道侧壁夹住 payload，否则冲量会被立刻弹掉；托盘围栏仍负责接住。`GRAVITY` 2100、`AIR_DRAG`、`RESTITUTION`、`TRAY_RESTITUTION` 0.62、`METER_EXIT_SPEED` 220、罩内 0.96 沉降阻尼均未改。
- 测试：冲量非零、左右都能抽到、绝对值在范围内；落地时间仍 ≤ 0.55 秒，有弹跳、不瞬移，偏转超过 24px，停在托盘上。
- 视觉：`docs/shots/rr_v0495_candy_roll.mp4`（720×1280）。球从出球口偏一侧落下，碰到托盘弹跳后滚着停下。
